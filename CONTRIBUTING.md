# Contributing

cemainou is made by RT Design Studio and used by our own team every day. Thank you for helping.

- **Feedback and bugs**: the feedback button inside cemainou is the fastest way (an admin can choose to send it to us), or open an issue here
  with the version, what you did, what you expected and what happened.
- **Ideas and questions**: in [Discussions](https://github.com/rtdesignstudio/cemainou/discussions): describe the problem you want solved; we keep the product small on purpose, so we say "no" often.
- **Pull requests**: welcome for fixes. For anything larger, open an issue first so we can agree on the approach. This repository is published from
  our main one, so we bring an accepted change over by hand and credit you in the commit and the changelog. By sending a pull request you agree
  that your contribution is licensed under the project's license ([LICENSE.md](LICENSE.md)).
- **Security**: see [SECURITY.md](SECURITY.md); never in a public issue.

Development setup and tests: see the README ("Development"). Code, docs and commit messages are in English; all tests must pass (`php artisan test`).
